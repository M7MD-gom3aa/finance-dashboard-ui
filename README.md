# Mudabbir | Finance Dashboard

Mudabbir is a personal finance dashboard designed for Arabic users. It is built with pure HTML and CSS, with no frameworks, no libraries, and no JavaScript. The whole page is written right-to-left (RTL) and adapts to different screen sizes, so it works on mobile, tablet, and desktop.

The dashboard gives a quick overview of someone's money in one place:

- **Summary cards:** current balance, income, and expenses, with the percentage change for each.
- **Recent activities:** the latest actions on the account, such as opening a savings account or adding a new card.
- **Recent transactions:** a table showing who the payment was to or from, the category, the date, the status (completed or pending), and the amount.
- **Monthly bills:** the total of monthly bills, with each bill showing its amount and how many days are left until it is due.
- **Budget overview:** the total budget, how much is used and how much remains, plus a progress bar for each spending category.
- **Income vs. expenses:** a weekly bar chart built with CSS only.
- **Accounts summary:** the current account, savings account, and credit card with their balances.
- **Payment methods:** Visa, Mastercard, and PayPal shown as cards that flip in 3D to show their back side when hovered over or focused.

The page also includes a fixed sidebar for navigation and quick actions, and a header with the user profile, search, and notifications. Accessibility was taken into account by using semantic HTML and ARIA attributes, so the page works well with screen readers and keyboard navigation.

## Technologies Used

- **HTML5**: semantic elements, RTL support, and ARIA attributes for accessibility
- **CSS3**: Grid, Flexbox, CSS variables, nesting, media queries, 3D transforms, pseudo-elements, gradients, and transitions
- **Font Awesome 6.7.2**: icons
- **Google Fonts**: IBM Plex Sans Arabic and Exo 2
